# Cloudfake Status

Een fictieve statuspagina, gebouwd met Hugo en Tailwind CSS. De verificatiecheckbox weigert iedere poging met toenemend droge feedback.

## Ontwikkelen

```bash
npm install
npm run setup:hugo
npm run build:css
npm run dev
```

## Productiebuild

```bash
npm run build
```

De statische site wordt naar `public/` geschreven.
